# Configuration VS Code pour Lotocrini

## Prérequis
1. Java JDK 17 ou supérieur
2. JavaFX SDK 25.0.1 installé à : `C:/javafx-sdk-25/javafx-sdk-25.0.1/`
3. VS Code avec l'extension "Extension Pack for Java"

## Installation
1. Cloner le projet
2. Ouvrir dans VS Code
3. Les extensions recommandées seront proposées automatiquement
